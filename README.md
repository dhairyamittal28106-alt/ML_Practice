# Machine Learning Practice

Study materials and notebooks for machine learning and NLP. ML/ covers regression, classification, clustering, model selection, ensembles, and PCA. NLP/ contains notes and a project notebook.

    python -m venv .venv
    pip install jupyter numpy pandas matplotlib seaborn scikit-learn
    jupyter notebook

Activate the environment first. Open notebooks from ML/ or NLP/. Some require external Kaggle datasets; download them and adjust paths. Dependencies vary by notebook.

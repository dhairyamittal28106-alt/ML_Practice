# Machine Learning Practice

A study collection of Jupyter notebooks, PDFs, and notes covering machine learning and NLP. The examples include regression, classification, clustering, ensemble methods, grid search, dimensionality reduction, car-price prediction, Titanic models, heart/insurance data, and an NLP project.

## Contents

- `ML/`: machine-learning notebooks and reference material
- `NLP/`: NLP notes, project notebook, and training text

## Open notebooks

Create a Python environment and install common notebook dependencies:

    python -m venv .venv
    # Activate the environment, then:
    pip install jupyter numpy pandas matplotlib seaborn scikit-learn
    jupyter notebook

Open a notebook under `ML/` or `NLP/`. Some notebooks rely on external Kaggle datasets (including a Ford car-price dataset); download the data and update its input path before running. Exact dependencies vary by notebook.
